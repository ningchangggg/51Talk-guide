# 51Talk 2027 創作者拍攝指南（手機版）

給 51Talk 2027 合作創作者看的拍攝指南。根目錄是七位總覽（知寧自己用，`#ep1`～`#ep7` 切換）；每位創作者拿到的是自己的子網址（單人版，沒有選主題區）。

- 網站：https://ningchangggg.github.io/51Talk-guide/
- 來源檔在 iCloud 的 51Talk 品牌資料夾（`51Talk_2027_創作者拍攝指南_手機版.html`）；`index.html` 由 `./build.sh` 產生，不要手改。
- 單人版來源在 iCloud `2027_KOL個別企劃_工作檔/拍攝指南/單人版/`；`build.sh` 會一併產生 `<key>/index.html`。
- 更新：改來源檔 → `./build.sh` → `git add -A && git commit -m "<年.月>：<改了什麼>" && git push`
